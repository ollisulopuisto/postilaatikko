# P-047: virtual-folder refresh

Local review branch: `agent/P-047-virtual-refresh`, based on main `c766bc3`.

- Added an explicit refresh control for the active virtual folder. It recomputes
  the cached index, resets the cursor, reloads the live list and restarts the
  existing online-count lifecycle. Visible rows stay in place during refresh.
- Refresh is disabled while busy. A navigation guard prevents an old cache
  refresh from resetting the next folder. The cache-update event does not start
  a duplicate reload during manual refresh.
- Canceled backend searches return cancellation rather than provider issues;
  expected cancellations do not become list/search errors. Real provider
  failures remain visible. Deadline failures are not hidden.
- English and Finnish refresh labels added; other locales use English fallback.
