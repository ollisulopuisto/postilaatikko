# UI base diagnostics: empty virtual folders (UX-001)

Task UX-001 of the D-002 plan. Repository part only. Everything that needs the
user's real mail device is listed under "Pending on the device" and is not
claimed as verified.

Base: `origin/main` at `d920258`.

## Root cause of empty windowed virtual folders

The app writes a message date with the Go SQLite driver as a `time.Time`. The
driver stores that as Go's `String()` form, for example
`2026-10-26 10:00:00 +0300 EEST`. SQLite's `unixepoch()` cannot read that form
and returns NULL (measured here, including for `+0000 UTC`).

Two queries computed a date window with `unixepoch(date)`:

- `internal/message/virtual_folder_queries.go`, the conversation CTE
  (`latest_date_epoch`) that feeds the list, the count and search.
- `internal/virtualfolder/store.go`, `UnreadCounts`, which feeds the sidebar badge.

With a NULL epoch, `latest_date_epoch >= ?` is never true. So a virtual folder
with a 7 day, 30 day, 90 day or 1 year window listed nothing, counted zero and
showed no unread badge, while the same folder with "all time" listed its
conversations, in the wrong order because the sort key was NULL too.

## Fix integrated here

`database.UnixEpochSQL(column)` reads RFC 3339, SQLite datetime and Go
`String()` dates, with or without fractional seconds and with named or unnamed
zones, and returns NULL for anything else. Both queries use it. The conversation
subject is also coalesced to an empty string so a missing subject cannot make
the row unreadable.

This is the date handling from candidate commit `e1b1c90`
(`integration/p037-review`), re-checked and covered by new tests:

| Test | What it pins |
| --- | --- |
| `internal/database` `TestUnixEpochSQL` | Nine stored forms, including a fractional second and a negative unnamed offset |
| `internal/message` `TestVirtualFolderDateWindowFindsStoredGoTimes` | Count and list for windows all, 7d and 1y over Go-stored dates; newest first |
| `internal/virtualfolder` `TestStore_UnreadCountsWithDateWindowForGoTimes` | The sidebar unread count for a windowed view |

Each was run red before the fix: windows 7d and 1y listed 0 conversations, the
order was wrong, and the unread count was 0.
